# GP-KAWADER
Kawader - an AI-powered Applicant Tracking System that uses CV parsing, semantic search (Qwen3-Embedding-0.6B), and RAG-based LLM re-ranking (Qwen-Reranker-0.6B) to match candidates with job requirements. Generates explainable AI ranking reports and flags missing mandatory requirements - while keeping the final hiring decision with HR.
